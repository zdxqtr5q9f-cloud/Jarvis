# Jarvis: рабочее состояние (зафиксировано 2026-10-01)

Локальный голосовой ассистент Jarvis (isair/jarvis) на MacBook Pro M5 Max, macOS 26, Ollama 0.32.14. Русский язык: STT, чат, озвучка.

## Версия
- Приложение: **2.3.0** (asset `575514360`, установлено 23.09.2026). Обновление не требовалось.
- Код для справки читался из локальной копии **2.2.2** (папка Runtime): схема конфига `_config_version: 3` совпадает, детали 2.3.0 не проверялись.

## Управление голосом
- **Стоп озвучки: «Shut up!»** (английская фраза; русское «стоп» не распознаётся приложением как стоп-слово). Также «Джарвис, стоп» (через модель, ~7–9 с).
- Obsidian: говорить «найди **в Obsidian** …» (иначе выбирается `localFiles`). Бюджет адаптера: 8 вызовов на сеанс.
- Горячие клавиши Hammerspoon (если установлены): Ctrl+Opt+Cmd+S тишина (авто-звук через 40 с), Ctrl+Opt+Cmd+J перезапуск Jarvis.

## Известные ограничения (не лечатся конфигом)
- Задержка ответа ~18–28 с: судья 2–3 с, работа приложения ~7 с, ответ 6–15 с (запрос ~3,4 тыс. токенов, кэш префикса между репликами не работает).
- `queue full`: очередь аудио 64 блока зашита в коде, Jarvis частично глухой, пока обрабатывает запрос.
- Эхо: при озвучке через динамики Mac микрофон слышит Jarvis; горячее окно иногда принимает его эхо как запрос (самоответ). Лечится наушниками (вывод) при микрофоне MacBook.
- После стопа аватар продолжает шевелить губами (баг приложения).
- Веб-поиск: DuckDuckGo отдаёт bot-challenge; работает только Википедия-fallback (по-русски, если Whisper определил `ru`). Единственная штатная замена: ключ Brave.
- `localFiles` может читать/писать/удалять файлы в домашней папке без подтверждения (код инструмента); защита только в промпте.

## Бэкапы и откат (на Mac)
- Каждая правка делала папку `~/JarvisBackups/<тип>-<дата-время>/` с `config_dir/`, `before.masked.json`, `after.masked.json` и `rollback.sh`.
- Снимок «известно хорошо»: `~/JarvisBackups/GOOD-final-<дата>/` (конфиг, копия `jarvis.db`, `ollama list`); восстановление: закрыть Jarvis, `cp -p <снимок>/config_dir/config.json ~/.config/jarvis/config.json`, запустить.
- Помощник правок: `bash ~/jarvis_cfg.sh ключ=значение` (закрывает Jarvis штатно, бэкап, правка, diff, перезапуск).
- Файлы Application Support/Jarvis (ваши адаптеры, ExternalIndex, Backups) не менялись.
